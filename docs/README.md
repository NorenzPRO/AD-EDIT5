## 技術仕様書 / Technical Documentation

AD-EDIT5の公開技術仕様書は、公式サイトで公開しています。

導入・初期設定、スキン構築、CMSの内部構造、各エディタ、APIなどに関する仕様書を参照できます。

**[AD-EDIT5 公式技術仕様書一覧](https://adedit.net/docs/)**

### 配布パッケージに含まれる仕様書

GitHub Releasesで配布している `adedit5.1.0.pack.zip` には、`/docs/` フォルダに公開技術仕様書33ファイルが同梱されています。

同梱仕様書はv5.1.0リリース時点のものです。最新の仕様については公式サイトをご確認ください。

### English

The AD-EDIT5 v5.1.0 distribution package includes 33 technical documentation files in the `/docs/` directory.

These documents correspond to the v5.1.0 release. For the latest documentation and updates, please visit:

https://adedit.net/docs/

# AD-EDIT5

**Perl CGI製の軽量オープンソースCMS — AIとの協働によるWeb開発を支援**

AD-EDIT5は、有限会社のれんずプロ（NorenzPRO）が開発・公開している、Perl CGIベースのオープンソースCMSです。

HTML・CSSによる自由なサイト設計と、CMSによるコンテンツ管理を両立したハイブリッドCMSです。

## AIを活用した開発・カスタマイズ

AD-EDIT5では、AIによる開発支援を想定し、CMSの構造や動作、設定方法などをMarkdown形式の技術仕様書として整備・公開しています。

これらの仕様書をChatGPT、Codex、ClaudeなどのAI開発支援ツールに参照させることで、人間が自然言語で指示を出し、AIと協働しながらWebサイトの構築やCMSのカスタマイズ、保守作業などを進められるようにすることを目指しています。

**基本的な考え方**

- 人間が開発方針や作業内容を指示する
- AIが技術仕様書を参照し、CMSの構造や仕様を理解する
- AIが仕様に基づいてコードの作成・修正を支援する
- 人間が変更内容を確認・検証する

AIが仕様を理解するための技術情報を一般公開することで、特定のAIサービスに依存しない開発環境を目指しています。

※ AD-EDIT5自体に生成AIが組み込まれているわけではありません。外部のAI開発支援ツールとの協働を想定した設計・ドキュメント公開方針です。

## About AD-EDIT5

**Lightweight Open-Source Hybrid CMS with AI-Readable Technical Documentation**

AD-EDIT5 is a lightweight, open-source hybrid CMS built with Perl CGI and developed by NorenzPRO in Japan.

It provides flexible content management while allowing developers to maintain control over their website's HTML and CSS.

### AI-Assisted Development

AD-EDIT5 provides publicly available technical documentation in Markdown format, designed to support AI-assisted development and customization.

Developers can provide these documents to AI coding assistants, such as ChatGPT, Codex, or Claude, and use natural-language instructions to guide website development, customization, and maintenance.

The documentation helps AI tools understand the CMS architecture, specifications, and expected behavior.

Human review and testing remain essential.

**Documentation:** https://adedit.net/docs/

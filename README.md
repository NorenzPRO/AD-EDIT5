# AD-EDIT5

**Perl CGIで動作する軽量オープンソースCMS**
AD-EDIT5は、有限会社のれんずプロ（NorenzPRO）が開発・公開している、Perl CGIベースのオープンソースCMSです。
HTML・CSSによる自由なサイト設計と、CMSによるコンテンツ管理を両立したハイブリッドCMSです。

## About AD-EDIT5

AD-EDIT5 is a lightweight, open-source hybrid CMS built with Perl CGI and developed by NorenzPRO in Japan.

It provides flexible content management while allowing developers to maintain full control over their website's HTML and CSS.

**Official website:** https://adedit.net/

**Download:** https://adedit.net/download/
